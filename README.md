# Münsel Drönme

Polski czytnik codziennej praktyki Wielkiego Współczującego. Tekst tybetański, zapis fonetyczny i polski przekład pochodzą z kopii aplikacji Munsel Dronme.

Serwis działa pod adresem [munsel-dronme.arybszleger.com](https://munsel-dronme.arybszleger.com/).

Uruchom lokalnie poleceniami `npm ci` i `npm run dev`. Polecenie `npm run lint` sprawdza typy, a `npm run build` tworzy statyczny serwis w katalogu `dist`. Zmiany na gałęzi `main` są publikowane przez GitHub Pages.
